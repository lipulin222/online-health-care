从「想了解」到「24 周陪跑」

左列是用户看到的页面与动作，右列是系统 / AI / 医生侧的流转。五个阶段一一对应，页面名可点开对应 Demo。

01

入口与评估

状态：未开始 · 用户还不知道自己适不适合
用户旅程
  1. 打开线上服务，看到科学减重卡
    「未开始」状态，两个入口：想了解什么（科普）/ 快速评估（约 1 分钟）。
    线上服务首页
  2. 先看科普，判断跟自己像不像
    作用机制、适用人群、安全边界、花费与用法。
    科普知识库
  3. 快速评估：一屏一题，共 10 题
    单选点完自动翻页，多选停顿 800ms 后自动进入下一题；不设倒计时。
    首诊评估
  4. 确认提交内容
    逐题汇总，每行可「修改」，改完自动回到汇总；确认后才提交。
  5. 等 3 秒，拿到评估报告
    中转页三步进度 + 转圈，完成后自动进入减重评估报告。
    减重评估报告
系统 / AI 流转
  1. 入口归因 + 卡片状态机
    记录来源渠道；卡片按阶段 1–5 与「第 N 天」展示，评估落点随阶段切换。
    系统
  2. 出题 + 校验
    按题型渲染，身高体重实时算 BMI；未答完不允许提交。
    系统
  3. 安全规则拦截（命中即停）
    备孕 / 哺乳、甲状腺髓样癌、胰腺炎等命中后不放行，只给「需要医生先确认」的出路，不下结论。
    风险分支
  4. 生成减重评估报告
    五个维度：减重必要性 / 方式适用性（GLP-1 匹配度）/ 预期效果 / 营养支持 / 用药方案。
    AI系统
  5. 给出减重建议等级（1–4 档）
    本例 3 / 4「可以开始减重」；报告页只做初步评估，不诊断、不开方。
    AI
评估完成 · 进入成交
02

成交与支付

状态：看完报告，决定要不要开始
用户旅程
  1. 读报告：6 个模块可折叠
    结论头带建议等级；吸底显示首诊套餐 ¥790（原价 1,380）。
  2. 点「开始科学减重」→ 支付
    订单明细：商品名 + 单价、优惠券（暂无可用）、小计；微信支付。
    支付页
  3. 支付成功
    绿色对勾 + 5 秒倒计时，自动进入预约；也可点文字链看「已购套餐」。
    支付成功页已购套餐
系统流转
  1. 报告落库
    问卷答案 + 已关联健康数据 + 建议等级，作为后续面诊与随访的底稿。
    系统
  2. 订单创建 → 待支付
    首诊套餐 ¥790：医生面诊 400 + 药物 580 + 医疗助理 300 + AI 陪跑 100（套餐价）。
    系统
  3. 支付回调 → 订单「待预约」
    同时写入「已购套餐」（有效期 12 个月）、发支付成功事件。
    系统
已支付 · 进入就诊
03

预约与到店

状态：钱付了，等医生面诊、开方、拿药
用户旅程
  1. 预约就诊：日期 / 网点 / 医生 / 时段
    科室页签（成人减重）、5 天可选、按网点筛选、医生卡与院区时段。
    预约就诊
  2. 到店面诊，当场开方
    全职内科医生评估：确认方案、开处方、说明用药与常见反应。
  3. 护士注射 + 取药，当日开始
    现场注射 1 次并取药，回家后按周自行注射。
  4. 分支：无法到店
    改为视频面诊；药品由冷链配送到家，注射与保存由护士线上指导。
    例外流程
系统 / 医生 / 仓库
  1. 号源锁定 → 预约单
    按网点与医生排班占用号源，生成预约单并推送到店提醒。
    系统
  2. 面诊记录 + 处方开具
    处方药必须经医生评估后开具；不合适用药则说明原因，按规则退款或改约。
    医生
  3. 发药 / 冷链出库
    到店由药房发药并登记注射；异地走冷链，物流单号回传订单。
    仓库护士
  4. 订单转「进行中」，首页切「开启日」
    首次回到首页看到开启日卡片（第 1 天）：起点数据 + 旅程条 + 「开始第 1 天」。
    开启日
已开始用药 · 进入陪跑
04

陪跑与随访

状态：进行中 · 24 周里最长的一段
用户旅程
  1. 记录体重（每周 1 次就够）
    卡片右上「记录体重」；还没有记录时显示起始体重 + 引导，而不是 −0kg。
    进行中 · 第 1 天进行中 · 第 28 天
  2. 随时问 AI 减重助理
    带阶段与周次上下文，问副作用、漏服、平台期、饮食怎么吃。
  3. 看减重月报
    本月体重曲线、用药与随访汇总、下月调整建议。
    减重月报
  4. 第 4 / 12 周做疗程随访评估
    自评用药反应、食欲、体重变化，拿到下一步建议。
    随访评估
系统 / AI / 医生
  1. 数据入档与趋势判定
    体重、腰围入库 → BMI、周变化、平台期与下降过快判定。
    系统
  2. 提醒引擎
    随访、续药、复查、饮食、运动、面部评估等 8 条规则按阶段轮换触达。
    系统
  3. 随访结论 → 医生确认
    维持 / 升档 / 减量 / 停药，均由医生按反应与数据判断。
    AI医生
  4. 月报生成
    满 4 周自动汇总一次，用户可随时回看历史月份。
    系统
随访完成 · 决定续or停
05

续购与结营

状态：续费 / 维持期 · 决定是否继续
用户旅程
  1. 随访两周内 → 「线上续药」
    首页主按钮直接续药；超过两周没随访，按钮回到「快速评估」。
    续费阶段
  2. 24 周结营 → 回顾
    减重人格 + 关键数据（−8.6kg、腰围 −9.5cm、打卡 78 次、复查 3 次）。
    结营回顾
  3. 维持期：定期复查
    停药后的重点是维持，复查提醒转为每月 1 次。
    维持期
系统 / 医生 / 仓库
  1. 续方 → 冷链到户
    按上次随访结论开方，不开新评估；冷链发货、物流可见。
    医生仓库
  2. 依从性与效果统计
    打卡次数、复查次数、体重与腰围变化，用于回顾页与医生复评。
    系统
  3. 结营归档，转维持期
    生成回顾（人格 7 型判定）→ 状态转「维持期」，进入长期随访池。
    AI系统
